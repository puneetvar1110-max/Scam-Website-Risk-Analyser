# Scam Website Risk Analyser

A beginner-friendly Python cybersecurity project that analyses website URLs and identifies potentially suspicious indicators.

## Features
- HTTP and HTTPS detection
- URL length analysis
- Suspicious keyword detection
- IPv4 and IPv6 address detection
- Private and public IP identification
- Risk score calculation
- Low, Medium and High risk classification

## Technologies Used
- Python
- ipaddress module
- urllib.parse module

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python scam_analyser.py
```

## Disclaimer
This project uses basic heuristic-based checks for educational purposes. It does not guarantee that a website is safe or malicious.
